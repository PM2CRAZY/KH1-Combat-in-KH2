# Tester requests

A chat between testers and the coding assistant, kept in a file. The tester writes what they want in a box, the assistant replies in its own box, the tester answers, and so on, the same as a normal chat. When the tester is happy, they give the go-ahead and the assistant starts coding. When they're satisfied with the result, they write `Close`.

Each new thread goes in the Requests section below, under its own `## Title`, separated from the next one by a line (`---`). The assistant moves it into its own file, `testers/<thread>/<thread>.md`. Finished threads move to `tester-requests-archive.md`.

A tester's box:

```
> [!note] Tester YourName
> What you'd like.
```
